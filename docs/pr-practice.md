# PR 연습

이 문서는 FindYU 팀의 Pull Request 생성과 검토 과정을 연습하기 위한 파일입니다.

- 작업 브랜치: `practice/kimsbo-pr-test`
- 병합 대상 브랜치: `Front-end`

## 연습 순서

1. PR의 Files changed 탭에서 추가된 문서를 확인합니다.
2. 문서의 원하는 줄에 리뷰 댓글을 남깁니다.
3. 연습을 마치면 PR을 병합하거나, 변경 사항을 반영하지 않으려면 Close pull request로 닫습니다.

이 변경은 문서만 추가하며 애플리케이션 동작에는 영향을 주지 않습니다.
