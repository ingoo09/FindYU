# FindYU 해커톤 공통 시작 프롬프트

Codex 또는 Claude Code에서 FindYU 저장소를 열고 **아래 두 버전 중 한 블록만 복사**한다. 공통 파일 3개와 자기 역할 명세 1개를 같은 메시지에 첨부한다. 별도로 복사할 역할별 프롬프트는 없다.

## 첨부할 파일 4개

1. [README.md](README.md) — 구현명세 폴더의 임베딩·검색 모드 변경표
2. [00_공통.md](00_공통.md) — 공통 구현 명세
3. [2026-11-25-findyu-hackathon.md](plans/2026-11-25-findyu-hackathon.md) — 5시간 실행 계획
4. 아래 표에서 **자기 역할 명세 하나**

| 담당자 | 역할 | 도구 | 역할 명세 | 실행 계획에서 맡은 작업 |
|---|---|---|---|---|
| 최인구 | `PM·통합` | Codex | [01_PM_통합.md](01_PM_통합.md) | 1·9 |
| 최준서 | `AI` | Codex | [02_AI.md](02_AI.md) | 2 |
| 권기백 | `백엔드·DB` | Claude Code | [03_백엔드_DB.md](03_백엔드_DB.md) | 3·4, 9의 백필 |
| 김승보 | `프론트엔드` | Codex | [04_프론트엔드.md](04_프론트엔드.md) | 5·6·8 |
| 이수형 | `Dashboard` | Codex | [05_Dashboard.md](05_Dashboard.md) | 7 |

[팀원 준비·전달 체크리스트](plans/2026-11-25-findyu-team-inputs.md)는 본인이 확인한다. FactChat 키는 필요한 담당자가 `backend/.env`에 직접 설정한다. 사용할 도구에 입력하는 값은 키가 설정됐는지 여부뿐이다.

## 버전 A · 수정 없이 복사

```text
FindYU 해커톤 구현을 시작해줘. 첨부한 역할별 명세 한 개에서 내 이름과 역할을 찾아줘. 실호출 준비 상태는 전달하지 않았으니 mock으로 시작해줘.

1. 첨부한 구현명세 폴더의 README.md 변경표, 00_공통.md, 역할 명세, 5시간 실행 계획을 읽어줘. 역할 파일이 없거나 둘 이상이거나, 명시한 역할과 파일이 다르면 작업 전에 맞는 역할 파일만 확인해줘. 역할 명세 하단의 시작 예시는 참고로 읽고, 실제 작업 번호와 순서는 실행 계획에서 찾아줘.
2. 사진 후보의 임베딩 선별과 검색 모드는 첨부 README 변경표를 따라줘. 자연어 후보는 기존 장소·시각·최신순을 써줘. 수동 등록은 등록 분석 호출 0회이며, 저장 후 사진 임베딩 1회 시도와 구분해줘. 정확한 API 요청·응답은 작업 기준 브랜치의 최신 docs/API.md를 따라줘.
3. 저장소의 AGENTS.md를 읽고, Claude Code라면 CLAUDE.md도 확인해줘. 현재 작업 브랜치와 기준 SHA를 확인하고, 기존 변경을 보존하면서 최신 main을 기준으로 해당 역할의 작업 브랜치에서 진행해줘. 필요한 규칙이나 API 문서를 찾을 수 없으면 관련 계약을 추측하지 말고 찾지 못한 파일을 적어줘.
4. 내 소유 범위에서 실행 계획의 첫 미완료 작업부터 진행해줘. 우선할 작업 번호를 적었으면 내 역할에 배정되고 선행 조건을 만족하는 경우에 먼저 진행해줘. 이미 병합된 기능은 재사용하고, 다른 역할의 선행 변경을 기다릴 때는 가능한 부분을 mock으로 검증해줘. 실호출 준비 상태가 설정됨일 때만 키 값을 출력하지 않고 설정 여부를 확인한 뒤, 계획에 정한 실호출 검증 단계에서 진행해줘.
5. 변경 파일, 실제 테스트와 결과, 담당자에게 전달할 변경 요청, 남은 사항을 한국어로 정리해줘.
```

## 버전 B · 필요한 값만 채워 복사

| 표기 | 보내기 전에 할 일 | 예시 |
|---|---|---|
| `{이름}`, `{역할}` | **필수.** 위 역할 표에 맞게 채우고 중괄호를 지운다. | `나는 최준서이며, 담당은 AI다.` |
| `[실호출 준비 상태: 값]` | 선택. `설정됨`, `미설정`, `해당 없음` 중 하나를 적고 대괄호를 지운다. 생략할 때는 줄 전체를 삭제한다. | `실호출 준비 상태: 설정됨` |
| `[우선할 작업 번호: 값]` | 선택. 내 역할에 배정된 번호를 적고 대괄호를 지운다. 생략할 때는 줄 전체를 삭제한다. | `우선할 작업 번호: 2` |
